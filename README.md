# onroute_app

A new Flutter project.


### Het project opstarten
**Huidige app installatie**
Voordat het project gerunned kan worden moeten er een aantal dingen geïnstalleerd worden.

1. Open het project in VS Code
2. Open een terminal (View > Terminal)
3. Update de dependecies
```
dart pub get
```
4. Installeer `arcgis_maps_core`
```
dart run arcgis_maps install
```

Nu alle benodigde ArcGIS dependencies gedownload zijn moeten de API keys nog gezet worden.

Deze worden uitgelezen uit een `.env` bestand. Maak dit bestand aan in de root van het project. 
Vul het vervolgens als volgt: `API_KEY=AAPTx...` 

Met dit geïnstalleerd te hebben is het project gereed om op te starten. 


**Nieuwe app installatie**
Om een nieuw project te installeren zijn meer stappen voor nodig. Dit staat volledig beschreven door ArcGIS op: https://developers.arcgis.com/flutter/install-and-set-up/
